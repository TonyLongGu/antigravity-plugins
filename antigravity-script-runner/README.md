# 腳本右鍵執行工具 (Script Runner)

為 **Cursor**、**Google Antigravity IDE** 與 **Visual Studio Code (VS Code)** 提供在左側檔案總管、編輯器或分頁標籤按右鍵直接在內建終端機執行腳本與多媒體檢視的原生擴充套件。

---

## 支援格式與功能

1. **Python 腳本 (`.py`)**
   - 右鍵選單 / 編輯器右上角 ▶ 按鈕：**執行 Python 腳本**
   - 自動儲存未存檔內容，於專屬 PowerShell 終端機調用 `py -u` 執行。

2. **批次檔 (`.bat` / `.cmd`)**
   - 右鍵選單（上方）：**執行批次檔**（一般使用者身分直接在內建整合終端機中執行）
   - 右鍵選單（下方）：**執行批次檔 (系統管理員)**（彈出 Windows UAC 提權並於獨立視窗安全執行）
   - 編輯器右上角 ▶ 按鈕：預設快速以一般身分執行。

3. **PowerShell 腳本 (`.ps1`)**
   - 右鍵選單（上方）：**執行 PowerShell 腳本**（一般身分自動附加 `-ExecutionPolicy Bypass` 於內建終端機執行）
   - 右鍵選單（下方）：**執行 PowerShell 腳本 (系統管理員)**（彈出 Windows UAC 提權並於獨立視窗安全執行）
   - 編輯器右上角 ▶ 按鈕：預設快速以一般身分執行。

4. **資料夾圖片檢視工具 (Image Viewer)**
   - **右鍵選單**：在左側檔案總管任意資料夾或圖片檔案按右鍵，選擇 **「檢視圖片」**。
   - **檔案總管雙擊開檔（檔案分頁）**：於檔案總管雙擊圖片檔，會以分頁標題為「檔名」的檔案分頁開啟並自動進入放大檢視。退出放大檢視（`Esc`、**滑鼠右鍵**或右上角 ✕）會**自動轉為標題為「資料夾名」的畫廊分頁並在畫廊中定位該圖**，直接檢視父層資料夾的全部圖片；由於檔名分頁不會殘留，之後再次雙擊同一張圖片必定能重新放大開啟。
   - **內容區獨立視窗**：於編輯器內容區以分頁開啟專屬工具面板，完整載入資料夾內的圖片（支援 `.png`、`.jpg`、`.jpeg`、`.webp`、`.gif`、`.svg`、`.bmp`、`.ico`、`.avif`、`.tiff` 等）。
   - **畫廊功能**：
      - **壓住右鍵拖曳滾動**：在圖片列表任意處按住滑鼠右鍵拖曳（支援 4.5x 高速抓手手勢），向上推即可快速往後翻閱瀏覽，流暢俐落無需特地瞄準滾動條。
     - 縮圖尺寸滑桿（110px ~ 360px 即時響應式切換）。
     - 即時檔名搜尋與高亮篩選。
     - 多維度排序（檔名自然排序、檔案大小、修改時間）。
     - 支援一鍵切換「包含子資料夾」遞迴檢視。
   - **高精度大圖檢視器 (Lightbox)**：
     - 點擊任一縮圖進入全視窗檢視。
     - **滑鼠滾輪縮放**：以滑鼠游標為精準錨點（Cursor-Anchored Zoom），平滑縮放游標所指之細節。
     - **滑鼠左鍵拖曳**：按住滑鼠左鍵自由平移拖曳（Pan），支援全域指針鎖定（Pointer Capture）防出界脫手。
     - **雙擊畫布**：在「最適視窗大小 (Fit)」與「1:1 原始解析度」之間切換。
     - **快捷鍵與滑鼠操作**：`←` / `→` 切換上一張/下一張、`R` 順時針旋轉 90°、`+` / `-` 縮放、`Delete` 刪除圖片（彈出確認視窗後安全移至資源回收筒）、`Esc` 或**滑鼠右鍵**退出檢視器、`G` **展開為資料夾畫廊**（僅檔案分頁顯示；會轉為「資料夾名」畫廊分頁並於畫廊中定位該圖）。

5. **資料夾聲音檢視工具 (Audio Viewer)**
   - **右鍵選單**：在左側檔案總管任意資料夾或音訊檔案按右鍵，選擇 **「檢視聲音」**。右鍵選單嚴格依照「檢視圖片」→「檢視聲音」→「檢視影片」排列。
   - **檔案總管雙擊開檔（檔案分頁）**：於檔案總管雙擊音訊檔，會以分頁標題為「檔名」的檔案分頁開啟並自動播放。退出播放列（`Esc`、底部播放列**滑鼠右鍵**或 ✕）會**自動轉為標題為「資料夾名」的畫廊分頁並在畫廊中定位該檔**，直接檢視父層資料夾的全部音訊；由於檔名分頁不會殘留，之後再次雙擊同一個檔案必定能重新播放。
   - **內容區獨立視窗**：於編輯器分頁開啟聲音工具面板，完整載入資料夾內的音訊（支援 `.mp3`、`.wav`、`.flac`、`.m4a`、`.ogg`、`.aac`、`.wma`、`.aiff`、`.opus`、`.weba` 等）。若直接在音訊檔案上按右鍵開啟，會自動定位並即時播放該首音訊。
   - **畫廊功能**：
     - **壓住右鍵拖曳滾動**：支援 4.5x 高速抓手手勢快速滾動翻閱。
     - 精美音訊卡片與**滑鼠懸停快捷播放/暫停**、播放中動態聲波能量條與黑膠光碟旋轉特效。
     - 卡片尺寸滑桿（160px ~ 360px，支援 `Ctrl + 滑鼠滾輪` 縮放）。
     - 即時檔名搜尋與篩選、多維度排序（檔名、時長、檔案大小、時間）、包含子資料夾遞迴搜尋。
     - 滑鼠左鍵框選 (Marquee) 與批量操作列（複製絕對路徑清單、刪除移至資源回收筒）。
   - **高性能沉浸式音訊播放列（底部常駐播放器）**：
     - 點擊卡片即可於畫面底部展開沉浸式播放列。
     - **Web Audio API 即時聲波頻譜視覺化**：播放時動態分析頻率資料，即時繪製高幀率霓虹漸層頻譜能量波形。
     - **黑膠唱片旋轉舞臺**：播放中唱片優雅旋轉，暫停時靜止。
     - **解耦 Seek 尋道機制**：拖曳進度條平滑精準，懸停顯示時間 Tooltip。
     - **滑鼠右鍵退出**：在底部播放列任意處點擊**滑鼠右鍵**或按 `Esc` 鍵即可立即退出播放列（與圖片/影片檢視器手感完全一致）。
     - **豐富播控與快捷鍵**：預設播放一次即停止；支援 `Space` 播放/暫停、`←` / `→` 快退/快進 5 秒、`↑` / `↓` 音量調整、`[` / `]` 上一首/下一首、`C` 自動連播切換（預設關閉）、`R` 單曲循環切換、`M` 靜音、倍速選單 (0.5x ~ 2.0x)、`O` 系統播放器開啟。

6. **資料夾影片檢視工具 (Video Viewer)**
   - **右鍵選單**：在左側檔案總管任意資料夾或影片檔案按右鍵，選擇 **「檢視影片」**。
   - **檔案總管雙擊開檔（檔案分頁）**：於檔案總管雙擊影片檔，會以分頁標題為「檔名」的檔案分頁開啟並自動播放。退出播放器（`Esc`、**滑鼠右鍵**或右上角 ✕）會**自動轉為標題為「資料夾名」的畫廊分頁並在畫廊中定位該檔**，直接檢視父層資料夾的全部影片；由於檔名分頁不會殘留，之後再次雙擊同一部影片必定能重新播放。
   - **內容區獨立視窗**：於編輯器分頁開啟影片工具面板，完整載入資料夾內的影片（支援 `.mp4`、`.webm`、`.mkv`、`.mov`、`.avi`、`.wmv`、`.flv`、`.m4v`、`.ts`、`.ogv` 等）。若直接在影片檔案上按右鍵開啟，會自動定位並直接播放該影片。
   - **畫廊功能**：
     - **壓住右鍵拖曳滾動**：支援 4.5x 高速抓手手勢快速滾動翻閱。
     - 16:9 影片縮圖卡片與**滑鼠懸停預覽播放**。
     - 縮圖尺寸滑桿（180px ~ 460px，支援 `Ctrl + 滑鼠滾輪` 縮放）。
     - 即時檔名搜尋與篩選、多維度排序、包含子資料夾遞迴搜尋。
     - 滑鼠左鍵框選 (Marquee) 與批量操作列（複製絕對路徑清單、刪除移至資源回收筒）。
   - **高性能自訂影片播放器 (Player Modal)**：
     - 點擊卡片開啟全視窗沉浸式播放器。
     - **解耦 Seek 尋道機制**：遵循 `web-video-player-guide` 標準，拖曳時 60fps 流暢反饋且不頻繁發起解碼請求，放開瞬間平滑尋道，徹底杜絕解碼管線死鎖與畫面跳動。
     - **自動隱藏游標與控制列**：播放中滑鼠靜止 2.4 秒自動隱藏，維持純淨觀影體驗。
     - **滑鼠右鍵退出**：在播放器畫面任意處點擊**滑鼠右鍵**或按 `Esc` 鍵即可立即退出播放器（與圖片檢視器退出手感完全一致）。
     - **豐富控制項與快捷鍵**：預設播放一次即停止；控制列整合循環播放與倍速切換，支援 `Space` 播放/暫停、`←` / `→` 快退/快進 5 秒、`↑` / `↓` 音量調整、`[` / `]` 上一部/下一部、`C` 自動連播切換（預設關閉）、`R` 循環播放切換、`M` 靜音、倍速選單 (0.5x ~ 2.0x)、`O` 系統播放器開啟。

7. **開檔分頁與畫廊分頁（重要行為）**

   | 開啟方式 | 分頁標題 | 退出放大檢視／播放（`Esc`、滑鼠右鍵、✕） | 放大檢視工具列的「展開為資料夾畫廊」 |
   | :--- | :--- | :--- | :--- |
   | 檔案總管**雙擊**多媒體檔（IDE 預設開檔） | `檔名`（例如 `cat.png`） | **自動轉為 `資料夾名` 畫廊分頁並在畫廊中定位該檔**（直接檢視父層資料夾全部檔案）；檔名分頁不會殘留，下次雙擊同一檔案仍可重新開啟 | 與退出同效（提供明確入口） |
   | 檔案總管右鍵 **「檢視圖片／聲音／影片」** | `圖片 / 聲音 / 影片: 資料夾名` | 僅退出放大檢視／播放，**留在畫廊**繼續瀏覽 | 不顯示（此分頁本身即為畫廊） |

   - 分頁標題由 VS Code 原生決定（自訂編輯器固定顯示檔名，擴充套件無法自訂分頁標題），因此改以「**檔案分頁＝該檔放大檢視**、**畫廊分頁＝資料夾畫廊**」的雙層設計：退出放大檢視時檔案分頁會自動「收斂」為資料夾畫廊分頁，既能看到父層資料夾所有檔案，也不會留下無法再次點開的殘留分頁。
   - 已知行為：IDE 重新載入或拖曳分頁造成 Webview 重建時，為避免自動播放，該分頁會停在畫廊；此時於畫廊雙擊卡片即可重新放大，或關閉該分頁後再由檔案總管雙擊開檔。
   - 刪除正在檢視的檔案時，檔案分頁會自動關閉，不會殘留指向已刪除檔案的分頁。

## 擴充套件設定 (Settings)

您可在 IDE 設定（`settings.json`）中微調以下選項：

| 設定項目 | 類型 | 預設值 | 說明 |
| :--- | :--- | :--- | :--- |
| `scriptRunner.runAsAdmin` | `boolean` | `true` | **是否預設以系統管理員身分 (Administrator) 執行腳本**。<br>• `true`：彈出 Windows UAC 確認並在提權獨立視窗執行。<br>• `false`：直接在 IDE 內部的整合終端機執行。 |
| `scriptRunner.keepWindowOpen` | `boolean` | `true` | **以管理員執行時，是否在執行完畢後保持視窗開啟**（防止報錯或執行完瞬間閃退，便於檢視輸出）。 |
| `scriptRunner.locale` | `string` | 跟隨 IDE | **介面語系**（`zh-TW` / `en`）。未設定時自動跟隨 Cursor / VS Code / Antigravity 顯示語言，並相容舊設定 `antigravity.locale`。 |

## 安裝與卸載方式 (支援 Cursor、Antigravity IDE 與 VS Code)

腳本具備智慧偵測能力，會自動辨識本機已安裝的 IDE 環境（Cursor、VS Code、VS Code Insiders、Antigravity IDE）並按需掛載：

- **一鍵安裝**：在 PowerShell 執行 `.\install-extension.ps1`（或直接雙擊 `install-extension.bat`）。
- **一鍵卸載**：在 PowerShell 執行 `.\uninstall-extension.ps1`（或直接雙擊 `uninstall-extension.bat`）。
- **重載生效**：於 Cursor、Antigravity IDE 或 VS Code 按 `Ctrl + Shift + P` -> 選擇 `Developer: Reload Window`。

## 開發者驗證 (Tests)

本擴充套件附帶**零依賴**驗證套件（純 Node，無需 npm 安裝、無需啟動 IDE）。

```powershell
node tests/run-all.js      # 或 npm test
```

| 檔案 | 驗證內容 | 斷言數 |
| :--- | :--- | :--- |
| `tests/locales.check.js` | 三個檢視器 zh-TW / en 鍵完全對稱、無空值、程式碼與 HTML 引用的鍵皆存在 | 3 組 |
| `tests/frontend.dom.js` | 前端互動語意：檔案分頁／畫廊分頁 × `Esc`／右鍵／✕／`G`／按鈕，應送出正確訊息；含音訊刪檔續播與 `Esc` 優先序 | 61 |
| `tests/backend.smoke.js` | 以 mock vscode 載入 `extension.js`：開檔沿用分頁、展開為畫廊分頁且標題為資料夾名、原檔案分頁被關閉、既有畫廊分頁復用並收到 `revealInGallery`、`closeCustomEditor` 防誤關守門 | 63 |

- 全部通過時輸出 `ALL-SUITES-PASSED (3/3)`；任一失敗即回傳非零退出碼（可直接用於 git hook 或 CI）。
- `backend.smoke.js` 會在系統暫存目錄建立臨時素材，結束時自動刪除，並呼叫 `deactivate()` 關閉串流伺服器（避免行程殘留）。
- **覆蓋邊界（請務必理解）**：DOM 模擬不做版面計算，**視覺／CSS 佈局問題測不到**；mock vscode 也無法重現真實 VS Code 的分頁重用與 Webview 重建行為。改動 UI 後仍應在真實 IDE 做一次煙霧測試。
- 詳細說明、限制與「負對照」驗證心法見 [`tests/README.md`](./tests/README.md)。
