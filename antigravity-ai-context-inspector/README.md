# AI 上下文檢視器 (AI Context Inspector)

Google Antigravity IDE 原生側邊欄擴充套件，專門用來即時檢視每次對話時 AI 載入之 **Rules（常駐與條件規範）**、**Skills（技能）**、**MCP 伺服器與 API 工具** 以及 **工作區綁定**。

---

## 🌟 功能特點

1. **雙模式切換**：
   - ⚡ **當前環境配置**：直接掃描本機 10 個 Workspaces 與全域目錄，即時確認目前生效設定。
   - 📜 **最近對話快照**：精準解析 `transcript.jsonl` 日誌，100% 還原該次對話 AI 實際被注入的記憶上下文。
2. **歷史對話任務切換**：可下拉選擇歷史對話任務進行復盤與環境對比。
3. **一鍵跳轉開啟**：點擊任一項目旁的 `📄 開啟` 按鈕，立即在編輯器開啟對應的 `.md` 檔案。
4. **即時過濾與搜尋**：輸入關鍵字即時篩選 Rules / Skills / MCP 名稱與描述。
5. **一鍵複製摘要**：點擊頂部 `📋` 按鈕，將整份生效上下文整理為 Markdown 格式並複製至剪貼簿。
6. **免編譯 Junction 安裝**：隨改隨生效，開發與自訂極度敏捷。

---

## 🚀 一鍵安裝與啟用

1. 雙擊執行 `install-extension.bat`。
2. 於 Antigravity IDE 按快捷鍵 `Ctrl + Shift + P`，輸入並執行 `Developer: Reload Window`。
3. 點擊左側活動列圖示 **🤖 (AI 上下文檢視器)** 即可開啟面板！
